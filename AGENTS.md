# AGENTS.md

img is a Rust still-image CLI and library (JPEG, PNG, WebP, AVIF) that optimizes and converts images against a measured fidelity score. Input images are untrusted. Read [docs/CODEC-BOUNDARY.md](docs/CODEC-BOUNDARY.md) before changing a codec, limit or the file-publication path, and [docs/CLI.md](docs/CLI.md) before changing a flag, exit code or JSON field. Do not run formatters or change the pinned toolchain (`rust-toolchain.toml`). Use `TMPDIR=$PWD/.work/tmp` and `CARGO_BUILD_JOBS=4`.

## Verification

- Commands: `make test` (Rust tests with all features, GNU-tar package test, `tests/test_bench.py`) and `make lint` (`cargo check` at two feature sets, `cargo clippy --all-targets`). PR CI runs both on macOS ARM64 and `make ci` (the same checks) on Linux musl in the Alpine image.
- Costs on a busy M-series host (load about 20, 4 jobs, kache): `make test` warm 56 s (`benchmark_verify` is 32 s of it), cold 39 min; `make lint` warm 53 s, cold 29 min. The package test needs GNU tar, so it runs on Linux CI hosts with it and in `release.yml`, and is skipped on macOS and in the Alpine image.
- CLI flags, exit codes (0, 2, 3, 4, 5), JSON schema 1, streams, traversal and collisions: `tests/cli.rs`, `tests/baseline.rs`, `src/exit.rs` unit tests, `tests/deadlock.rs`, `tests/signals.rs`, `tests/timestamps.rs`; contract in `docs/CLI.md`.
- Formats and their limits (16,384 px side, 16 MP, 128 MiB input, 8 MiB metadata, 256 JPEG scans): JPEG `tests/jpeg_codec.rs`, PNG `tests/png_codec.rs`, WebP `tests/webp_codec.rs`, AVIF `tests/avif_codec.rs`, limits and file publication `tests/codec_boundary.rs`, color `tests/color_fidelity.rs`. Corrupt-input fuzzing: none (a scratch 30,900-run mutation sweep over 13 seeds found no crash, see TODO-DESLOP.md).
- Library API (`still`, `optimizer`, `publication`, `limits`, `error`, retained `operations`): `tests/optimizer.rs`, `tests/codec_boundary.rs`, `tests/perceptual_score.rs`, unit tests in `src/`. Consumers: none declared in this repository; the binary, tests, examples and benches are the only callers.
- Performance workload: `scripts/bench` (`make bench TIER=edit|change|scenario|full`, `make bench-check`) against the qualification corpus, gated by `perf-gate-ready`; its harness is covered by `tests/test_bench.py`. `make benchmark-verify` checks recorded results.
- Opt-in checks: `make decoder-reference-check`, `make metric-reference-check` (needs JPEG XL 0.12.0 tools), `make native-build-check` (fresh release build, allowlist of compiled C/C++).
- Components (non-blank, non-comment lines, `vendor/` excluded, 50.4k with 2.1k Python): `src/` 6.4k, `codecs/webpkit` 37.7k (WebP encoder snapshot, locally modified), `tests/` 2.0k, `benches/` and `examples/` 0.9k, `codecs/*-sys` shims 0.2k, Python 2.1k and extensionless scripts 0.8k. Deslop slices: the img crate (about 13k) and `codecs/webpkit`, one ticket per step each.
- Vendored trees (details and patches in [docs/VENDOR.md](docs/VENDOR.md), notices in [docs/PROVENANCE.md](docs/PROVENANCE.md)): libjpeg-turbo 3.2.1 (github.com/libjpeg-turbo/libjpeg-turbo, release tarball, patched), oxipng 10.2.1 (github.com/oxipng/oxipng `36f3ef8`, patched), libdeflater and libdeflate-sys 1.26.1 (github.com/libdeflater/libdeflater `260e1e9`, libdeflate v1.26), dav1d 1.5.4 (code.videolan.org/videolan/dav1d `191bdda`), fast-ssim2 0.9.1 (github.com/imazen/fast-ssim2 `b02184f`, patched), libjxl v0.11.1 for jpegli (`794a5dc`, patched) with Highway (`457c891`), libavif v1.4.2 (`bd32fb4`) and libaom v3.13.1 (`d772e33`), webpkit (github.com/P4suta/webpkit `cc1311e`, in `codecs/webpkit/`, see [docs/WEBP-IMPORT.md](docs/WEBP-IMPORT.md)).
