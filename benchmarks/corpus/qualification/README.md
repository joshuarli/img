# Qualification corpus

This frozen set contains 150 independent originals: 100 development inputs
and 50 holdouts. Keep the holdout split out of development and tuning; if used
for tuning, declare that use and obtain fresh holdouts. `source_id` identifies
an original, and no original belongs to both splits.

The Wikimedia Commons originals include 30 photographs, 20 archival grayscale
photographs, 20 photographic textures, and 10 scanned or printed text images.
Each manifest entry records the original URL, Commons file page, author,
license, SHA-256, dimensions and image header properties. Commons imageinfo
metadata provided the license and attribution. Images remain subject to any
applicable personality or other non-copyright rights.

The remaining 70 originals are generated by `scripts/qualification-corpus`:
10 grayscale, 10 RGB texture, 20 UI/text, and 30 synthetic images. The generator
code and its outputs are dedicated to the public domain under CC0-1.0. Each
entry records the generation parameters and a frozen hash. Procedural images
cover controlled encoder behaviors; they are not photographs.

Run from the repository root:

```sh
python3 -I scripts/qualification-corpus .work/qcorpus
```

The destination is an untracked cache. Downloads are sequential and verified
against the manifest; generated files are verified in the same way. Repeating
the command verifies existing files without downloading or regenerating them.
A changed or corrupt cached file fails verification; remove it to fetch or
generate the pinned original again. Do not commit image files.
